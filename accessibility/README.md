## :memo: <span id="description">Description</span>

In **Accessibility**, you’ll embark on a hands-on crash course in inclusive web design. Starting from real HTML/CSS starter files in the `accessibility` directory, you’ll work through a quiz of progressive tasks—from making focus states keyboard-visible and adding skip links to ensuring proper ARIA roles, semantic landmarks, sufficient color contrast, labeled form controls, and meaningful link text. Along the way you’ll validate against WCAG conformance levels (A, AA, AAA), test with assistive technologies, and internalize why accessibility isn’t just a feature but a fundamental requirement. By the end of this project you’ll be able to articulate ARIA’s purpose, WCAG criteria, the importance of accessibility, and the tools you need to build truly inclusive web experiences.

## :school: <span id="learning objective">Learning Objective</span>

Key skills developed:

- ARIA’s main purpose
- WCAG conformance levels (A, AA and AAA)
- The importance of Web Accessibility
- Tools to use for Web Accessibility
