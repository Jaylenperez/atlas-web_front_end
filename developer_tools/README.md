## :memo: <span id="description">Description</span>

**Developer tools** is a novice-level, hands-on lab where you’ll explore and master your browser’s built-in debugging and inspection suite using the sample site [dev-tools.hbtn.info](https://dev-tools.hbtn.info/). Through 30+ guided exercises, you’ll learn to:

- Emulate devices and test responsive layouts
- Inspect and live-edit HTML and CSS styles
- Force element states (hover, focus, etc.) and copy button styles
- Block network requests and audit file coverage
- Use the JavaScript console to inspect elements, run snippets, and log page info
- Analyze network activity: request counts, resource sizes, and caching policies
- Run Lighthouse audits for performance, accessibility, best practices, and SEO
- Examine application storage (cookies, sessionStorage) and service workers
- Inspect SSL/TLS certificate details in the Security panel
