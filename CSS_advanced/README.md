## :memo: <span id="description">Description</span>

In **CSS Advanced (Max’s Version)** you’ll take an existing HTML “advanced” page and elevate it into a pixel-perfect, Figma-driven design using only CSS. You’ll revisit CSS fundamentals—selectors, specificity, the box model—then apply those skills to craft headers, banners, quotes, video lists, membership cards, FAQ accordions, and footers that match every color value, font size, and spacing in the designer file. By the end of this project, you’ll be able to explain how CSS works under the hood and style any page from scratch without relying on external libraries or frameworks.

## :school: <span id="learning objective">Learning Objective</span>

Key skills developed:

- What is CSS
- How to add style to an element
- What is a class
- What is a selector
- How to compute CSS Specificity Value
- What are Box properties in CSS
- How does the browser load a webpage
