## :memo: <span id="description">Description</span>

**Flexbox** is an amateur-level, hands-on quiz designed to turn your static layouts into flexible, one-dimensional designs using the CSS Flexible Box module. Starting from a basic HTML/CSS template, you’ll progressively replace floats and grids with `display: flex`, learn to control the main and cross axes, and master alignment, spacing, and ordering of elements. Each task challenges you to apply a specific Flexbox property—wrapping service cards, reversing news items, flexifying headers and footers, and even restructuring an article layout—so that by the end, you’ll confidently build responsive, maintainable pages with pure HTML/CSS and no external libraries.

- Emulate devices and test responsive layouts
- Inspect and live-edit HTML and CSS styles
- Force element states (hover, focus, etc.) and copy button styles
- Block network requests and audit file coverage
- Use the JavaScript console to inspect elements, run snippets, and log page info
- Analyze network activity: request counts, resource sizes, and caching policies
- Run Lighthouse audits for performance, accessibility, best practices, and SEO
- Examine application storage (cookies, sessionStorage) and service workers
- Inspect SSL/TLS certificate details in the Security panel
