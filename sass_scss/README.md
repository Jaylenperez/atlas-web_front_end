## :memo: <span id="description">Description</span>

This project will guide you through building modular, maintainable styles using the Sass preprocessor. You will write pure SCSS files (no external frameworks) that demonstrate:

- Debugging output with `@debug`
- Variables for colors, fonts, and reusable values
- Nested selectors mirroring your HTML structure
- Mixins for common patterns (e.g., margins)
- Inheritance with `@extend` to share base styles
- Imports (`@import` / `@use`) to split your code into logical files
- Control directives (`@if`, `@for`, `@each`, `@while`) for dynamic rule generation
